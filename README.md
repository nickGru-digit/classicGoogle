# Classic Google
This is a site designed to mimic the appeareance and useability of google.com based on the first Wayback Machine archive of the homepage after 2000-01-01
The search bar takes you to modern Google, but just for fun, it takes out the AI Overview in the query.

https://web.archive.org/web/20000301105534/http://google.com/

For now, the alternate links on the site path to the Wayback versions, which will result in some shenanigans if you go back and forth. It tries to hide the toolbar at the top, but going between multiple pages will occasionally makee it reappear.
